# G.E.M. 邓紫棋粉丝致敬站

> **官网太丑了，所以我自己用 AI 写了一个。**

## 为什么有这个站

某天点开官方 iamgem.com，作为一个听了她十几年的歌迷，说实话有点看不下去——巡演信息就孤零零几行，曲目一张专辑页都没有，视觉更是停留在上个时代。

行吧，自己动手。全程 AI vibe coding，没有手写一行页面逻辑，想到哪做到哪，就长成了现在这样。纯爱好，图一乐，也图一个"我喜欢的歌手值得一个好看的站"。

## 这个站有什么

- **五个页面随便逛**：首页 / 音乐年表 / 巡演全记录 / 棋士联盟 / 出道历程
- **75 首歌全都能听**：每首歌点开就是 Apple 官方试听，歌词站内直接看（不用跳出去），看过的还会缓存在本地，第二次秒开
- **巡演一场不落**：四轮世界巡演 **171 站 / 317 场**，从 2011 年红磡到 2026 年深圳，每一站的日期、城市、场馆、连开几天都在——这是官网那几行数字远远给不了的（2026-10 校对：官网漏记的 12 场加场已逐场核实补齐，四轮总数 182/73/48/14 场与官方口径一致）
- **连她写的小说都有**：《启示路》恒藏版真书封 + 出版信息 + 银河奖战绩
- **页脚一键直达**：微博、抖音、小红书、YouTube、Instagram、Facebook、X，全都是官网挂的官方账号

## 怎么跑起来

```bash
npm install     # 装依赖
npm run dev     # 本地开发
npm run build   # 打包
npm run preview # 本地预览打包结果（端口 4173）
```

技术栈：Vite 8 + Vue 3 + Tailwind CSS v4，纯前端，没有后端，一个 `.env` 都不需要。

## 数据哪来的

都是公开渠道，如实交代：

- **曲目、试听、专辑封面**：iTunes 公开 API（艺人 ID 425208570，TW 区）
- **巡演场次**：官网 iamgem.com/tours，2026 年 9 月整理，四轮巡演一场一场抄下来的
- **歌词**：LRCLIB 开放接口，点开歌曲时实时拉取，看过的存浏览器缓存——**歌词全文不进这个代码库**，这条是底线

## 部署

推上 GitHub → [Vercel](https://vercel.com) 导入 → 完事。`vercel.json` 已经写好（路由回退），默认配置一路下一步就能上线。
